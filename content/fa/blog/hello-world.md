بلوک‌های کد با برجسته‌سازی نحوی نمایش داده می‌شوند و نام زبان به‌صورت برچسب در
گوشه نشان داده می‌شود.

```bash
npm install
npm run dev
```

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet("world"));
```

می‌توانید کد درون‌خطی مانند `const x = 42` را هم وسط جمله قرار دهید.

## پشتیبانی از ریاضیات و لاتک

حروفچینی درون‌خطی با یک علامت دلار: $O(n \log n)$.

$$O(n^2)$$

نماد O بزرگ برای دسته‌بندی الگوریتم‌ها بر اساس رشد زمان اجرا یا حافظه مصرفی با
افزایش اندازه ورودی استفاده می‌شود.

| پیچیدگی | نام |
|---|---|
| $O(1)$ | ثابت |
| $O(\log n)$ | لگاریتمی |
| $O(n)$ | خطی |
| $O(n \log n)$ | خطی-لگاریتمی |
| $O(n^2)$ | درجه دوم |
| $O(2^n)$ | نمایی |
| $O(n!)$ | فاکتوریل |

## معادلات مرتبط با نرم‌افزار

پیچیدگی جستجوی دودویی:

$$T(n) = O(\log n)$$

رابطه بازگشتی مرتب‌سازی ادغامی:

$$T(n) = 2T\!\left(\frac{n}{2}\right) + O(n)$$

آنتروپی شانون — معیاری برای اندازه‌گیری اطلاعات در داده‌ها:

$$H(X) = -\sum_{i=1}^{n} P(x_i) \log_2 P(x_i)$$

قانون امدال — شتاب نظری یک برنامه موازی:

$$S = \frac{1}{(1 - p) + \frac{p}{s}}$$

که در آن $p$ بخش موازی‌پذیر و $s$ تعداد پردازنده‌ها است.

فاصله اقلیدسی بین دو بردار ویژگی:

$$d(\mathbf{a}, \mathbf{b}) = \sqrt{\sum_{i=1}^{n} (a_i - b_i)^2}$$

دقت و فراخوانی در بازیابی اطلاعات:

$$P = \frac{TP}{TP + FP}, \qquad R = \frac{TP}{TP + FN}$$
