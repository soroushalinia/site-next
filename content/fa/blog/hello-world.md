# سلام دنیا

خوش آمدید! این پست برای نمایش قابلیت‌های وبلاگ نوشته شده است. [^1]

## عنوان‌ها و فهرست مطالب

هر عنوان `h1` تا `h3` در فهرست مطالب بالای صفحه همراه با شماره‌گذاری جمع‌آوری
می‌شود. برای پرش به هر بخش روی آن کلیک کنید.

### یک عنوان تو در تو

عنوان‌های سطح سوم زیر عنوان والد خود در فهرست مطالب قرار می‌گیرند.

## بلوک‌های کد

بلوک‌های کد با برجسته‌سازی نحوی نمایش داده می‌شوند و نام زبان به‌صورت برچسب در
گوشه نشان داده می‌شود.

```bash
npm install
npm run dev
```

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet("world"));
```

می‌توانید کد درون‌خطی مانند `const x = 42` را هم وسط جمله قرار دهید.

## نقل‌قول‌ها و فهرست‌ها

> نقل‌قول برای برجسته کردن یک ایده یا یک جمله عالی است.

فهرست‌های مرتب و نامرتب هر دو کار می‌کنند:

- قالب‌بندی مارک‌داون
- برجسته‌سازی کد
- پانویس‌ها [^2]

1. یک پست با مارک‌داون بنویسید
2. مقداری frontmatter اضافه کنید
3. منتشر کنید

## جمع‌بندی

همین بود. هر وقت آماده بودید این پست را با نوشته‌های خودتان جایگزین کنید.

[^1]: پانویس‌ها در پایین صفحه نمایش داده شده و به هر دو طرف لینک می‌شوند.
[^2]: این وبلاگ حتی شماره پانویس‌ها را برای زبان‌های راست‌به‌چپ بومی‌سازی می‌کند.
