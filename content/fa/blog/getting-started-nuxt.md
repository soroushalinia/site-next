# شروع کار با Nuxt 4

Nuxt 4 تجربه توسعه‌دهندگی بهبود یافته‌ای با ساختار دایرکتوری `app/` جدید و عملکرد بهتر ارائه می‌دهد.

## نصب

```bash
npx nuxi init my-app
cd my-app
npm install
npm run dev
```

## ساختار پروژه

## تست هدلاین؟

```text
app/
  components/
  layouts/
  pages/
  app.vue
nuxt.config.ts
```

## چرا Nuxt 4؟

سریع‌تر، تمیزتر و ماژولارتر از همیشه.[^1]

[^1]: برای اطلاعات بیشتر به مستندات رسمی Nuxt 4 مراجعه کنید.
